About the 8-Puzzle Problem

The 8-Puzzle is a sliding-tile puzzle played on a 3×3 grid with eight numbered tiles and one blank space. A move slides a tile into the blank, which is the same as moving the blank Up, Down, Left or Right.

The goal is to rearrange the tiles from an initial state to a goal state using the fewest moves.

State-space formulation:

  • State: arrangement of the 9 cells
  • Initial / Goal state: given by the user
  • Actions: move blank Up / Down / Left / Right
  • Transition cost: 1 per move

Only half of all 9!/2 = 181,440 arrangements are reachable from any given state, so solvability must be checked first.
